# 隐私政策

生效日期：2026 年 10 月 15 日

Lingua 用于文本翻译和图片文字识别。应用不设账号，不含广告、跟踪或开发者运营的翻译服务器。

## 本地翻译
图片文字识别与内置翻译模型均在 Mac 上运行。原文、译文、术语、图片与性能数据不会发送给开发者。原图仅保留在当前会话；历史记录保存识别文字和译文，不保存图片文件。仅当你执行粘贴时读取剪贴板图片，识别结束后清理临时图片。

## API 翻译
API 翻译为可选功能。首次向每个配置的 API 地址发送请求前，应用会征求你的同意。同意后，原文（含图片识别文字）、相关术语、语言和风格指令、模型名称会发送至该地址，原图不会发送。API Key 仅用于向你配置的服务认证。该服务如何保存和处理信息，取决于其条款与隐私政策。请仅在你的服务协议允许时提交机密信息。修改 API 地址需要再次同意；可在设置撤销授权，但撤销无法删除服务商已经收到的数据。

## 模型下载
只有你点击下载后，应用才会下载可选模型。Hugging Face、HF-Mirror 或你配置的镜像会收到普通下载请求，包括 IP 地址及模型文件路径，不会收到翻译文字、术语或 API Key。内置模型无需下载即可使用，镜像是第三方服务。

## 存储与控制
最近 100 条翻译、术语、偏好和下载的模型保存在应用沙盒内。可逐条删除历史与术语，也可在设置清空翻译记录。API Key 默认在内存使用，仅在点击保存后写入应用本地数据目录，按服务地址分别存储。凭据文件为本地明文文件，目录和文件权限仅允许当前用户访问，不使用 macOS 钥匙串。移除已保存的 Key 不会在服务商处撤销 Key。卸载应用不一定清理全部本地数据容器，请结合设置与 macOS 控制管理本地数据。

## 权限与更新
应用只请求访问你选择导入或导出的文件，网络用于可选 API 请求和模型下载。本版本没有统计分析或崩溃上传服务。如后续版本实质改变数据处理方式，会更新本政策和相应授权提示。
