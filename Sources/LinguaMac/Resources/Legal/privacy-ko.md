# 개인정보 처리방침

시행일: 2026년 10월 15일

Lingua는 텍스트 번역과 이미지 문자 인식을 제공합니다. 앱 계정, 광고, 추적 및 개발자가 운영하는 번역 서버는 없습니다.

## 로컬 처리
문자 인식과 내장 모델 번역은 Mac에서 실행됩니다. 원문, 번역문, 용어, 이미지 및 성능 정보는 개발자에게 전송하지 않습니다. 원본 이미지는 현재 세션에만 보관하며 기록에는 인식한 텍스트와 번역문을 저장합니다. 클립보드 이미지는 붙여넣을 때만 읽고 임시 파일은 인식 후 삭제합니다.

## API 번역
API 사용은 선택 사항입니다. 설정한 API 주소마다 첫 요청 전에 동의를 받습니다. 동의하면 원문(이미지에서 인식한 텍스트 포함), 관련 용어, 언어·문체 지시 및 모델 ID를 전송합니다. 원본 이미지는 전송하지 않습니다. API 키는 설정한 서비스 인증에만 사용합니다. 서비스의 보관 및 처리 방식에는 해당 서비스 약관과 개인정보 처리방침이 적용됩니다. 기밀 정보 전송이 계약상 허용되는지 확인해 주세요. 주소 변경 시 다시 동의해야 합니다. 설정에서 동의를 철회할 수 있으나 이미 서비스가 받은 정보를 삭제하지는 못합니다.

## 모델 다운로드
선택 모델은 다운로드 버튼을 누를 때만 받습니다. Hugging Face, HF-Mirror 또는 설정한 미러에는 IP 주소와 요청 파일 등 일반 다운로드 정보가 전달되며 번역문, 용어 또는 API 키는 전달되지 않습니다. 내장 모델은 다운로드 없이 사용할 수 있습니다. 미러는 제3자 서비스입니다.

## 저장과 관리
최근 번역 100개, 용어, 설정 및 모델은 앱 샌드박스에 저장됩니다. 기록과 용어를 개별 삭제하거나 설정에서 기록을 모두 지울 수 있습니다. API 키는 기본적으로 메모리에서 사용하고 저장을 선택한 경우에만 서비스 주소별로 앱의 로컬 데이터 디렉터리에 보관합니다. 인증 정보는 일반 텍스트 파일로 저장되며 디렉터리와 파일 권한은 현재 사용자만 접근할 수 있도록 제한됩니다. macOS 키체인은 사용하지 않습니다. 저장된 키 삭제는 서비스 측 키 폐기를 의미하지 않습니다. 앱 삭제 후에도 로컬 데이터 컨테이너가 남을 수 있습니다.

## 권한과 변경
선택한 가져오기·내보내기 파일에 접근하며 선택적 API 요청과 모델 다운로드에 네트워크를 사용합니다. 이 버전에는 분석 또는 충돌 업로드 기능이 없습니다. 처리 방식이 실질적으로 변경되면 이 방침과 동의 안내를 업데이트합니다.
