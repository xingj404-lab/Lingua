# プライバシーポリシー

発効日：2026年10月15日

Lingua はテキスト翻訳と画像の文字認識を行います。アカウント、広告、追跡、開発者が運営する翻訳サーバーはありません。

## ローカル処理
文字認識と内蔵モデルによる翻訳は Mac 上で実行されます。原文、訳文、用語集、画像、性能情報は開発者に送信されません。元の画像は現在のセッションでのみ保持され、履歴には認識文字と訳文が保存されます。クリップボードの画像は貼り付け時のみ読み取り、一時ファイルは認識後に削除します。

## API 翻訳
API は任意です。設定した各 API アドレスへの初回送信前に同意を求めます。同意すると、原文（画像の認識文字を含む）、関連用語、言語・文体の指示、モデル ID が送信されます。元の画像は送信しません。API キーは設定したサービスへの認証にのみ使用します。送信後の保存・処理はサービスの規約とプライバシーポリシーに従います。機密情報の送信が契約で許可されているか確認してください。アドレス変更時は再同意が必要です。設定で同意を撤回できますが、送信済みデータは削除できません。

## モデルのダウンロード
追加モデルは「ダウンロード」を選択したときのみ取得します。Hugging Face、HF-Mirror または設定したミラーに IP アドレスと要求ファイルなどの通常のダウンロード情報が送られます。翻訳文、用語、API キーは送信しません。内蔵モデルはダウンロード不要です。ミラーは第三者サービスです。

## 保存と管理
直近100件の翻訳、用語、設定、モデルはアプリのサンドボックスに保存されます。履歴・用語は個別に削除でき、設定から履歴全体を消去できます。API キーは通常メモリに保持し、「保存」を選んだ場合のみ、サービスアドレスごとにアプリのローカルデータディレクトリへ保存します。認証情報は平文ファイルに保存し、ディレクトリとファイルのアクセス権を現在のユーザーのみに制限します。macOS キーチェーンは使用しません。保存キーの削除はサービス側でのキー失効を意味しません。アンインストールしてもローカルデータコンテナが残る場合があります。

## 権限と変更
選択した入出力ファイルにアクセスし、任意の API 呼び出しとモデル取得にネットワークを使用します。本バージョンに分析やクラッシュ送信機能はありません。処理方法を大きく変更する場合は本ポリシーと同意画面を更新します。
